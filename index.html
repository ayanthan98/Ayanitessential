Turning on & using a computer
Desktop, laptop, touchpad basics
⌄
  • 1Press the power button and wait for the desktop to fully load before doing anything
  • 2Mouse: left click = select, right click = options menu, scroll wheel = scroll up/down the page
  • 3Touchpad (laptop): tap once = click, two-finger tap = right click, two-finger scroll = scroll page
  • 4To shut down properly: click Start → Power → Shut down. Never just close the lid without shutting down properly
  • 5Practice: open a programme (e.g. Notepad), close it, open another one, switch between open windows
Tip: Never press and hold the power button to force off — always use proper Shut Down unless the computer is completely frozen
📁
✓
Files & folders
Save, copy, move, rename, delete
⌄
  • 1Open File Explorer: press Windows + E — this shows all your files and folders
  • 2Create a new folder: right click on empty space → New → Folder → type a name → press Enter
  • 3Copy a file: right click → Copy → go to new folder → right click → Paste (or Ctrl+C then Ctrl+V)
  • 4Rename: right click file → Rename → type new name → press Enter
  • 5Delete: select the file → press Delete key → it goes to Recycle Bin (not permanently deleted yet)
  • 6Restore a deleted file: open Recycle Bin on desktop → right click the file → Restore
Practice taskCreate a folder called "My Documents", create a text file inside it, rename it, then delete it and restore it from Recycle Bin
⌨️
✓
Keyboard shortcuts
Save time with Ctrl+C, Ctrl+V and more
⌄
  • 1Ctrl + C = Copy selected text or file
  • 2Ctrl + V = Paste what you copied
  • 3Ctrl + X = Cut (moves the item instead of copying)
  • 4Ctrl + Z = Undo last action — very useful if you make a mistake!
  • 5Ctrl + S = Save the current document
  • 6Ctrl + A = Select all text or files at once
  • 7Alt + Tab = Switch between open windows quickly
  • 8Windows key = Open or close the Start menu
  • 9Ctrl + P = Print the current page or document
Practice taskOpen Notepad → type your full name → select all → copy → paste it 5 times below → undo using Ctrl+Z

✓
Connecting to the internet
WiFi, mobile hotspot, troubleshooting
⌄
  • 1Click the WiFi icon at the bottom right of the screen → select your network name → enter password → click Connect
  • 2Mobile hotspot: on your phone go to Settings → Hotspot → turn on → connect your laptop to it like normal WiFi
  • 3Check if connected: open browser → type google.com → if page loads, you are connected
  • 4If not connecting: click WiFi icon → Disconnect → wait 5 seconds → Connect again
  • 5If still no connection: restart the router (turn off, wait 30 seconds, turn on again)
Safety: Never connect to unknown public WiFi (at shops, parks) for important tasks like email login or banking — your information can be stolen

Email & accounts
Very important for university applications
👤
✓
Sign up — creating an account
Gmail, websites, government portals
⌄
  • 1Go to the website (e.g. gmail.com) → click "Create account" or "Sign up" button
  • 2Fill the form: First name, Last name, choose a username (e.g. dilnishaperera2005@gmail.com)
  • 3Create a strong password — use CAPITAL letters + small letters + numbers + symbols (e.g. Dilni@2005)
  • 4Enter your phone number → you will receive an SMS code → enter it to verify
  • 5Account is created — write the email address and password in a safe notebook at home
Important: Use your real name in your email address (e.g. dilnishaperera, not cutegirl123) — this email will be used for job applications and university forms
🔑
✓
Sign in & forgot password
Logging in, resetting passwords
⌄
  • 1Go to the website → click "Sign in" or "Log in" → enter your email → enter password → click Sign in
  • 2Forgot password: click "Forgot password?" → enter your email address → check your email inbox for a reset link
  • 3Click the reset link in the email → create a new password → sign in with the new password
  • 4On shared computers (school, library): always sign out after use — click profile photo (top right) → Sign out
  • 5Never tick "Remember password" on computers that are not yours
Practice taskSign in to Gmail → sign out → use the "Forgot password" flow to reset and sign back in

✓
Sending & receiving email
Gmail — compose, reply, attach files
⌄
  • 1Open gmail.com → sign in → your Inbox shows all received emails
  • 2Send a new email: click the Compose button (pencil icon, top left)
  • 3To: type the recipient's full email address (e.g. admissions@slithm.edu.lk)
  • 4Subject: write a short, clear title (e.g. "Inquiry about Scholarship — BSc Degree 2026")
  • 5Body: write your message politely. Start with a greeting, state your purpose, end with your name
  • 6Attach a file: click the paperclip icon → select file → wait for upload → then click Send
  • 7Reply: open an email → click Reply → type your response → click Send
  • 8CC = send a copy to another person too. BCC = send a hidden copy (they don't see each other)
Tip: Always write a proper Subject line — emails with no subject look unprofessional and may be ignored or go to spam
Practice taskCompose a formal email to an imaginary institute asking about course fees — include your name and contact in the message body

✓
Strong passwords & account safety
Protect your accounts from hackers
⌄
  • 1A strong password = at least 8 characters, with Capital letters + small letters + numbers + symbols
  • 2Never use: your name, birthday, "password", "123456" — hackers try these first
  • 3Use different passwords for different accounts — especially your main email and bank accounts
  • 4Enable 2-step verification on Gmail: Settings → Security → 2-step verification → Turn on
  • 5Never share your password with anyone — even close friends. Real companies will NEVER ask for your password
  • 6Write passwords in a physical notebook kept safely at home — not saved in WhatsApp messages or phone notes
Warning: If someone says they are from Google, Gmail, or a bank and asks for your password — it is a scam. Hang up or close the message immediately

Documents & online tools

✓
Google Docs / Microsoft Word
Type, format, save and share documents
⌄
  • 1Open docs.google.com → sign in with Gmail → click "+ Blank" to start a new document
  • 2Type your content — Google Docs auto-saves every few seconds (you will see "Saved" at the top)
  • 3Format text: select text → click B (bold), I (italic), U (underline) in the toolbar
  • 4Change font size: select text → click the number box in toolbar → type the size you want (e.g. 12)
  • 5Download as Word file: File → Download → Microsoft Word (.docx)
  • 6Download as PDF: File → Download → PDF Document (.pdf)
  • 7Share with someone: click blue Share button (top right) → enter their email → click Send

Google Sheets — basic spreadsheet
Tables, simple formulas, budget tracking
⌄
  • 1Open sheets.google.com → click "+ Blank" to start a new spreadsheet
  • 2Each box is called a cell — cells are named by column letter + row number (e.g. A1, B2, C3)
  • 3Click a cell and start typing — press Tab to move right, press Enter to move down
  • 4Simple sum formula: click empty cell → type =SUM(A1:A5) → press Enter — adds all values from A1 to A5
  • 5You already know maths — spreadsheet formulas are just maths written in cells. Example: =A1+B1 adds two cells
  • 6Download as Excel: File → Download → Microsoft Excel (.xlsx)

Searching the internet smartly
Google tips, safe browsing, official sources
⌄
  • 1Use specific search words — instead of "SLITHM" search "SLITHM degree 2026 application fees Sri Lanka"
  • 2To find a PDF document: add filetype:pdf — e.g. "UGC handbook 2026 filetype:pdf"
  • 3To search only one website: add site: — e.g. "scholarships site:ugc.ac.lk"
  • 4Safe websites: look for the padlock icon in the browser address bar (https) — this means the site is secure
  • 5Government websites end in .gov.lk — universities end in .ac.lk — these are the most trustworthy in Sri Lanka
  • 6Never click pop-ups that say "You won a prize!" or "Your computer has a virus!" — these are always scams
Tip: For official information about university admissions, fees, and courses — always go directly to the official website (.ac.lk or .gov.lk) rather than Facebook posts or YouTube videos

Downloading & uploading files
Online application forms, PDFs, scanning documents
⌄
  • 1Download a file: click the download link on the website → file saves automatically to your Downloads folder
  • 2Find downloaded files: open File Explorer (Windows + E) → click Downloads on the left side
  • 3Upload a file to a form: click "Choose file" or "Browse" button → find your file → click Open → it uploads
  • 4Scan documents using your phone: download CamScanner app (free) → scan certificate → save as PDF → send to yourself by email

Important for applications: Always save a digital copy of your NIC, A/L certificate, and O/L certificate as PDF — you will need to upload these for university and job applications

What is a computer network?
Internet, WiFi, router, IP address — explained simply
⌄
  • 1A network = computers connected together so they can share information with each other
  • 2The internet = a massive worldwide network connecting billions of devices across the whole world
  • 3A router = the box at your home that creates your WiFi and connects your home to the internet
  • 4An IP address = your device's unique address on the network — like a house number on the internet
  • 5To see your IP address: open browser → search "what is my ip" in Google → it shows your IP
  • 6LAN (Local Area Network) = your home or office network. WAN (Wide Area Network) = the internet itself
  • 7Bandwidth = how much data can travel through your connection — higher bandwidth = faster internet
Think of it like this: The internet is like the national road network. Your router is the gate of your house. Your IP address is your house number. Data travels like vehicles on these roads.

Online scams & how to stay safe
Phishing, fake jobs, fraud — how to spot them
⌄
  • 1Phishing = fake emails pretending to be your bank, Google, or government — asking for your password. NEVER click these links
  • 2Check the sender email address carefully — scammers use fake addresses like "google-support@gmail123.net" (notice: not google.com)
  • 3Fake job offers: if any job asks you to pay money first before you start working — it is 100% a scam, always
  • 4Never send your NIC photo, bank account details, or passwords to anyone you don't fully know and trust in real life
  • 5If something seems too good to be true ("You won Rs. 500,000! Click here!") — it is always a scam
  • 6On Facebook and Instagram: strangers offering foreign jobs, scholarships, or "easy money" online are almost always scams
Important for girls: Sri Lanka has seen many social media scams targeting young women — fake "scholarship" and "modelling" opportunities that lead to dangerous situations. Always verify through official websites and tell a trusted adult

Google Drive — cloud storage
Store & backup files online, access from anywhere
⌄
  • 1Cloud storage = saving your files on the internet so you can access them from any device, anywhere
  • 2Open drive.google.com → sign in with Gmail → you get 15GB free storage automatically
  • 3Upload a file: click "+ New" → File upload → select your file → it uploads to the cloud
  • 4Access from phone: install Google Drive app → sign in with same Gmail → all files appear on your phone
  • 5Share a file: right click the file → Share → enter email or click "Copy link" → share the link
  • 6Always backup these important documents to Drive: NIC copy, A/L certificate, O/L certificate, birth certificate

Professional communication
WhatsApp, Zoom, LinkedIn, formal messaging
⌄
  • 1For professional WhatsApp messages: use full sentences, no slang, no abbreviations like "u" or "r u free"
  • 2Formal message structure: Greeting → purpose → your name. Example: "Good morning, I am Dilnisha Perera. I am writing to inquire about..."
  • 3Zoom / Google Meet: used for online interviews and classes — install free app → click Join with meeting link given to you
  • 4Before any video call: check your background is clean and tidy, lighting is good, no loud noise around you
  • 5Create a LinkedIn profile (linkedin.com) — add your photo, education, skills. Employers and universities search here
  • 6Email signature: add to every professional email — Name, Contact number, Current qualification

Career-ready skills

✓
Creating a professional CV
Google Docs template, save as PDF, name the file
⌄
  • 1Open docs.google.com → click Template Gallery (top right) → search "resume" → choose a clean, simple one
  • 2Fill in: Full name, address, phone number, email address, education (A/L results, O/L results), any extra courses, skills
  • 3Keep it to 1 page for a fresh graduate — clear and simple is better than long and complicated
  • 4Download as PDF: File → Download → PDF Document (.pdf) — always send your CV as PDF, not Word format
  • 5Name the file properly: YourName_CV.pdf — never leave it as "document1.pdf" or "untitled.pdf"
  • 6No need to add a photo unless specifically asked — keep the design clean and professional

Using AI tools (Claude & ChatGPT)
Free study help, writing assistance, research
⌄
  • 1Claude (claude.ai) and ChatGPT (chatgpt.com) are free AI assistants — sign up with your Gmail account
  • 2Ask it to explain anything: "Explain what actuarial science is in simple words" or "What is the difference between SLITHM and NSBM?"
  • 3Ask it to help write: "Write a formal email to SLITHM asking about scholarship eligibility for low-income students"
  • 4Use for studying: "Give me 10 practice questions on basic accounting" or "Explain compound interest step by step"
  • 5Use for translations: "Translate this English university letter into Sinhala"
  • 6Always double-check important facts from AI (especially official deadlines, fees, and government rules) on official websites
Free advantage: AI tools can replace expensive private tutors for many subjects — use them daily for study. This is one of the biggest free advantages available to students right now
